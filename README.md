# Murad Hossain — Lightweight Research Portfolio

This is the optimized **multi-page** research portfolio, ready for GitHub Pages.

## Included
- Six HTML pages (`index.html`, `research.html`, `projects.html`, `experience.html`, `awards.html`, `cv.html`)
- CSS, JavaScript and optimized WebP project/award previews
- Downloadable academic CV (`assets/docs/Murad_Hossain_CV.pdf`)

## Optimized
Large research manuscript/thesis documents and certificate scans were intentionally omitted. All corresponding site links now open optimized preview images instead of missing documents. The written research/project details remain on the pages.

The original documents have **not** been altered; retain your original source ZIP as your private archive. If you wish to publish a full manuscript later, check co-author permissions, correctness and status first.

## Upload to GitHub Pages (browser)
1. Create or open your PUBLIC repository `hossainmuradme/murad-hossain-research`.
2. Upload **the contents of this folder** to the repository root (not the enclosing folder).
3. Commit to the `main` branch.
4. Go to **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
5. After deployment, visit `https://hossainmuradme.github.io/murad-hossain-research/`.

For future updates, replace files in the same repository; do not change your other website.
